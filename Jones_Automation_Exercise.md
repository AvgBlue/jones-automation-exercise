# Jones Automation - Exercise

## Intro

In this exercise you will need to create a simple automation using the Playwright library.

Playwright is a javascript library that allows you to simulate Chrome usage by writing javascript code, this is why it is optimal for web sites automation.

Playwright runs on Node so you first must install and run Node:

https://nodejs.org/en/download/

Node can be installed both in Windows and Linux, many installation guides are available online.

Playwright library:

https://playwright.dev/docs/library

API guide:

https://github.com/microsoft/playwright

Examples:

https://github.com/playwright-community/playwright-jest-examples

## The exercise

Create an automation file to check the following site:

https://test.netlify.app/

**The automation flow should:**

- Type values in the Name, Email, Phone, Company and Website fields.
- Create a screenshot of the page before clicking the “Request a call back” button.
- **Bonus:** Change the Number of Employees from 1-10 to 51-500
- Click the “Request a call back” button.
- Write to the console.log when reaching the thank you page.
